#### Description:

Policonnect is a web-based application designed to keep users up to date with the latest political news from around the world. Built using HTML, CSS, and JavaScript, the app fetches real-time news articles using the NewsAPI and displays them in a clean, modern interface.

The main goal of Policonnect is to help students, researchers, and politically curious individuals access reliable and timely political information all in one place. The project emphasizes simplicity and accessibility while providing up-to-date headlines sorted by publication date.

### Features:
- Real-time political news in English
- Responsive and clean layout
- Stylish color theme: purple, blue, white, and black
- External links to full articles for further reading

### Technical Details:
- Built with: HTML5, CSS3, JavaScript (ES6)
- API used: NewsAPI.org (with personal API key)
- News sorted by date and filtered by political topics
- Hosted on GitHub Pages

This project was developed as a final project for CS50. It aims to combine technical skills with a real-world theme: global politics. Through this project, I deepened my understanding of API integration, DOM manipulation, and responsive design.
